# 🧮 Scientific Calculator (Python Tkinter)

A fully functional **scientific calculator** built with **Python and Tkinter**. This project provides a graphical user interface (GUI) that performs basic arithmetic operations as well as advanced mathematical calculations such as trigonometric functions, logarithms, and constants.

---

## ✨ Features

### ➕ Basic Calculations

* Addition
* Subtraction
* Multiplication
* Division
* Decimal calculations

### 🔬 Scientific Operations

* Sine (`sin`)
* Cosine (`cos`)
* Tangent (`tan`)
* Logarithm (`log`)
* Square root (`√`)
* Power operations
* Pi constant (`π`)
* Parentheses for complex expressions

### 🖥 Graphical User Interface

* Interactive calculator buttons
* User-friendly display screen
* Organized layout using Tkinter widgets
* Real-time expression evaluation

## ⚙️ How It Works

1. The user enters an expression through the calculator buttons.
2. Button events trigger corresponding Python functions.
3. Mathematical operations are processed.
4. The result is displayed on the calculator screen.

---
## ▶️ How to Run

### Requirements

* Python 3.x installed on your machine.
* Tkinter (included by default with most Python installations).

### Steps

1. Clone this repository:

```bash
git clone https://github.com/kozetchanny52-gif/FULL-CALCULATOR-WITH-TKINTER.git
```

2. Open the project folder:

```bash
cd FULL-CALCULATOR-WITH-TKINTER
```

3. Run the calculator application:

```bash
python CALC.py
```

4. The **Tkinter Scientific Calculator** window will launch, and you can start performing calculations.

---

### Alternative

If you already downloaded the project, simply run:

```bash
python CALC.py
```
